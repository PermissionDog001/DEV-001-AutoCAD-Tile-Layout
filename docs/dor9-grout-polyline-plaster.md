# DOR9-A 灰缝、闭合多段线与抹灰完成面规则草案

状态：DOR9-A 规则已冻结，已授权按冻结规则实施生产代码；DOR8 AutoCAD 2021 DWG 副本实机验收仍未完成。

日期：2026-08-04

## 1. 任务目标

DOR9 计划在不破坏现有四个命令流程的前提下，为 `TILEORTHOUI` 复杂房间流程增加：

1. 可自定义的砖间灰缝宽度，默认 `1.5 mm`。
2. AutoCAD 闭合正交多段线作为房间边界输入。
3. 可自定义的房间内抹灰厚度，并根据原始边界生成抹灰完成面轮廓，作为排版计算边界。
4. 工作树分类、Git 基线提交和最终正式版本发布准备。

DOR8 的正式写回保护继续有效：预览、取消、切换候选、失败和未确认状态零写入；正式写回继续只消费同源 `LayoutDrawingPlan` 的 `DivisionLines + Connections`。

## 2. 当前实现边界审计

- Core 当前使用 `AxisAlignedOrthogonalPolygon` 作为排版区域，`EngineeringOrthogonalDecisionRequest` 和 `EngineeringOrthogonalLayoutParameters` 只携带砖宽、砖高及现有项目/房间决策。
- `OrthogonalRoomValidator` 当前接收 `LineSegment3D` 集合，验证单一、连通、闭合、WCS 轴对齐正交环；分离环和洞口被拒绝。
- `LayoutDrawingPlan` 已保存房间轮廓、砖轮廓、分格线、连接边和诊断信息；DOR8 正式写回明确排除轮廓、诊断和中性连接线。
- AutoCAD 适配层目前没有闭合 `LWPOLYLINE`/`POLYLINE` 到 Core 正交边界的输入适配，也没有抹灰内偏移或灰缝参数入口。

## 3. 暂定设计方向

> 说明：本节 3.1–3.3 保留为规则冻结前的设计讨论记录；如与第 3.4 节冲突，以用户于 2026-08-04 确认的 DOR9-A 冻结规则为准。当前实现也遵循“原始边界 → 抹灰完成面 → 以完成面边界计算排版”的顺序。

以下内容只是实现建议，不代表已经冻结。

> 本节的原始建议保留作为讨论记录；DOR9-A 的冻结规则以第 3.4 节为准。

### 3.1 灰缝

- 参数名称暂定为 `GroutWidthMm`，单位为毫米，默认值 `1.5`，必须是有限且不小于 `0` 的数值。
- 砖的物理尺寸仍由 `TileWidth`/`TileHeight` 表示；灰缝只作用于相邻砖之间的排布间距，不改变砖本身尺寸。
- 灰缝计算必须进入 Core，候选生成、边砖实测尺寸、推荐/绝对下限比较和 `LayoutDrawingPlan` 必须使用同一结果。
- `TILE600`、`TILELAYOUT`、`TILEORTHO`、`TILEDOORRECT` 暂定继续使用现有 `0 mm` 行为；新参数先接入 `TILEORTHOUI`，避免改变既有命令契约。

必须先确认：

1. 房间边界与第一块砖之间是否计入灰缝；当前产品语言“砖与砖之间”更接近“不计入墙边灰缝”。
2. 正式图纸中灰缝如何表达：继续写一条分格/缝中心线，还是写出灰缝两侧的两条边界线。该选择会改变 `LayoutDrawingPlan` 和 DOR8 正式写回对象语义。
3. 灰缝是否参与边砖最小尺寸和项目绝对下限比较；建议比较实际砖尺寸，不把灰缝宽度误计为砖宽。
4. 当自定义灰缝导致某一方向无法容纳完整砖加有效余量时，是否按现有候选硬规则淘汰，还是保留为视觉确认候选。

### 3.2 闭合多段线

首期建议只支持以下输入：

- `LWPOLYLINE` 或传统二维 `POLYLINE`。
- 实体必须闭合、共面、单一外环、无自交、无重复/重叠边。
- 顶点段必须为 WCS X/Y 轴对齐直线；存在 bulge/圆弧段时拒绝并给出明确提示。
- 保留现有四条或多条 `LINE` 输入，不要求用户改图。
- AutoCAD 适配层负责读取实体、坐标系和高程，转换为 Core 的 `LineSegment3D`；Core 继续使用既有正交边界校验。

必须先确认：

1. 首期是否接受带洞多段线、多个外环或圆弧 bulge；建议首期全部拒绝。
2. 多段线存在共线连续顶点时是否自动合并；建议只做确定性的共线简化，不改变边界几何。
3. 多段线输入与四条 LINE 输入是否使用完全相同的门洞、主次区和候选流程；建议相同。
4. 原始多段线是否只读使用；建议不修改、不炸开、不移动原实体。

### 3.3 抹灰完成面

- 参数名称暂定为 `PlasterThicknessMm`，单位为毫米，默认值 `0`，必须是有限且不小于 `0` 的数值。
- 正值表示从原始房间边界向房间内部偏移；完成面作为排版计算轮廓，原始墙线/多段线不修改。
- 偏移应在 Core 中确定性生成，不能调用 AutoCAD OFFSET 作为算法来源。
- 偏移后若出现自交、边界消失、退化、无法保持正交或面积不满足公差，应拒绝当前输入并说明原因。
- 抹灰完成面默认只作为计算和只读预览依据，不作为 DOR8 正式写回对象；正式写回仍只写分格线和必要连接边。

必须先确认：

1. 厚度是统一四边数值，还是允许各墙分别输入；建议 DOR9 首期统一值。
2. 原始边界的语义是墙体内侧线、墙体中心线还是完成面外侧线；不同语义会改变偏移方向和距离。
3. 完成面轮廓是否需要提供一个只读显示开关；建议可以显示，但不写入正式图层。
4. 同一原始房间使用不同抹灰厚度时，DOR8 重复写回判定是否仍按原始房间范围拒绝；建议按原始房间身份/范围判重，避免同一房间因参数变化重复写入。

### 3.4 DOR9-A 已冻结规则（2026-08-04）

#### 3.4.1 灰缝

- `GroutWidthMm` 默认 `1.5 mm`，允许 `0`，必须为有限且非负数。
- 灰缝仅接入 `TILEORTHOUI`；`TILE600`、`TILELAYOUT`、`TILEORTHO`、`TILEDOORRECT` 保留并继续使用 `0 mm` 行为。
- 砖与砖之间设置完整灰缝；砖与墙之间设置宽度为灰缝一半的边界灰缝。灰缝为 `1.5 mm` 时，砖墙边界灰缝为 `0.75 mm`。
- 灰缝增加网格节距，但不改变砖的名义物理尺寸；边砖实际尺寸不按扣除灰缝后的占位节距计算。
- 推荐下限和项目绝对下限比较不包含灰缝占位节距。
- 灰缝引起边砖尺寸变化时，继续沿用 G3 硬规则、推荐规则、视觉确认规则、墙角对缝优先和对侧完整整砖/准确对缝资格门。
- 灰缝图面使用灰缝两侧边界线；预览与正式写回均显示。
- 墙角对缝比较灰缝中心位置，不比较灰缝任一侧边界位置。

#### 3.4.2 闭合多段线

- 首期只接受 AutoCAD `LWPOLYLINE` 和传统二维 `POLYLINE`；不接受 `Polyline3d`。
- 输入必须是闭合、单一外环、共面、WCS X/Y 轴对齐且允许现有微小近正交偏差的实体；不允许 bulge、圆弧、自交、洞、多外环或重复/重叠环。
- 允许当前 Core 已支持的轴对齐凹多边形。
- 共线连续顶点只做确定性的合并，不改变边界几何。
- 一间房只允许一个边界输入源，禁止混合 `LINE` 与多段线，也禁止多环输入。
- 多段线使用与当前 `LINE` 完全相同的近正交归一化规则、门洞、主次区、候选、预览、取消、失败和正式写回流程。
- 原始多段线只读使用，绝不修改、炸开、移动或写回原实体。

#### 3.4.3 抹灰完成面

- `PlasterThicknessMm` 默认 `0 mm`，允许 `0`，必须为有限且非负数；负值直接拒绝，不支持向外偏移。
- 原始边界语义冻结为完成面外侧线；正值表示从原始边界向房间内部偏移。
- 首期所有面使用统一厚度，不支持逐边厚度。
- 偏移后的凹角、窄部位和相交边必须保持 WCS 轴对齐，使用确定性的正交连接，不产生圆弧或 bulge。
- 偏移失败、自交、退化、面积不足或房间消失时，统一判定为输入无效：清除/失效旧预览、不生成候选、不写回任何对象。
- 完成面轮廓在厚度不为 `0 mm` 时写入正式图层；厚度为 `0 mm` 时不额外写入轮廓。原始 `LINE`/`POLYLINE` 始终不修改。
- 同一原始房间改变抹灰厚度后，正式写回重复判定仍按原始房间范围/身份，不按抹灰后的完成面范围判重。
- 门洞、控制区域、主次区和连接边均在抹灰完成面上定义；完成面变化后，已选数据同步向内偏移。
- 起铺西南角和墙角对缝评价按抹灰完成面的西南角。

#### 3.4.4 兼容边界

- G3 候选生成、推荐/绝对下限、墙角对缝优先、对侧完整整砖/准确对缝资格门不改变；DOR9 只改变输入边界、灰缝节距和同源绘图计划的几何数据。
- 预览、取消、失败和未确认状态继续零写入；正式写回继续使用同源 `LayoutDrawingPlan`，并只从其 `DivisionLines + Connections` 输出正式线对象。完成面正式轮廓必须作为该计划的正式线集合成员表达，不新增独立写回通道。

## 4. 建议实施顺序

1. DOR9-A 规则冻结后，先实现 Core 数据契约和确定性计算：原始边界先生成抹灰完成面，再以完成面边界计算排版。
2. 接入 AutoCAD `LWPOLYLINE`/二维 `POLYLINE` 读取和边界转换；原实体只读，沿用 `LINE` 的近正交归一化与下游流程。
3. 实现抹灰完成面内偏移、失败拒绝和已选门洞/控制区域/主次区/连接边的同步。
4. 接入灰缝参数、网格节距、实际砖尺寸判断、墙角灰缝中心对缝和同源 `LayoutDrawingPlan`。
5. 接入 UI 设置、自动预览、刷新、取消和旧预览失效，保持未确认状态零写入。
6. 接入正式写回；继续只消费同源计划的 `DivisionLines + Connections`，其中非零抹灰完成面轮廓作为 `DivisionLines` 成员表达。
7. 完成 Core/Adapter 自动测试、静态写入边界审计和性能检查。
8. 完成 AutoCAD 2021 DWG 副本实机验收；DOR8 既有实机收口仍需按专项清单单独记录，不与 DOR9 互相替代。
9. 盘点 working tree，先给出拟暂存文件清单；等待用户确认后再进行 Git 基线提交。
10. 全部验收通过后，再单独确认版本号、发布物、GitHub 可见性、标签、推送和 Release 发布。

## 5. 不在本阶段自行扩展

> DOR9-A 例外：抹灰厚度不为 `0 mm` 时，完成面轮廓按第 3.4.3 节作为同源 `LayoutDrawingPlan` 的 `DivisionLines` 成员写入正式图层；本节不扩展为砖块轮廓、诊断线、圆弧边界、带洞/多外环或逐边抹灰厚度的正式写回。

- 不改变 G3 候选生成、推荐/绝对下限、墙角对缝优先或对侧完整整砖/准确对缝资格门，除非用户另行冻结新规则。
- 不默认支持圆弧边界、带洞边界、多外环、非正交多段线或各墙不同抹灰厚度。
- 不把抹灰完成面、砖块轮廓、灰缝诊断或其他辅助线直接写入 DOR8 正式图层。
- 不在规则尚未确认时修改版本号、`dist`、Git 标签、远端或 GitHub Release。
