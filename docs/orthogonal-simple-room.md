# 正交简单房间边界与裁切

> 状态：OR1 与 OR2 自动质量门、AutoCAD 2021 实机验证均已通过
> 日期：2026-07-21；OR2 复核：2026-07-29
> Git 基线：`main` 提交 `6aa51d9`
> 边界：独立能力，不启动 M10，不修改版本或发布物

## 1. 首个最小里程碑

新增独立命令 `TILEORTHO`，支持由 4 条及以上模型空间 `LINE` 组成的单一 WCS 正交简单房间。已有 `TILE600` 和 `TILELAYOUT` 的选择数量、矩形语义、图层及消息保持不变，继续作为已验收兼容入口。

`TILEORTHO` 的首个里程碑只接受：

- 同一当前图纸、同一模型空间、同一 WCS 高程的独立 `LINE`；
- 每条线与 WCS X 或 Y 轴平行，图纸单位为毫米；
- 单一简单闭合环，无洞、无自交、无重复或部分重叠、无 T 形分叉、无悬挂边、无分离环；
- 选择顺序和每条 `LINE` 的起终点方向任意；
- 共线分段矩形、L 形凹多边形，以及满足同一契约的其他正交简单环。

任意斜边、旋转网格、洞口/柱、多外环、多房间通缝、灰缝、居中和窄砖优化不进入本里程碑。

## 2. 起铺锚点决策

### 2.1 方案比较

| 方案 | 优点 | 首个里程碑的问题 | 决策 |
|---|---|---|---|
| 区域包围盒四角 | 只有四个确定状态；选择顺序无关；矩形时与 SC1 坐标完全一致；无需新增点选 | 凹房间的包围盒角可能在室外，不能再宣称是第一块砖的房内角 | 采用，但改称“包围盒网格锚点” |
| 边界顶点 | 锚点一定在边界上 | 凹房间可能有很多顶点；必须新增顶点拾取、吸附、无效点和同点歧义规则 | 暂缓 |
| 任意 WCS 基准点 | 可扩展到走廊、中心线和跨房间通缝 | 必须同时冻结房外点、负向模数、双侧余量、点捕捉和跨房间基准 | 暂缓 |

### 2.2 冻结语义

`TILEORTHO` 继续复用 `TileLayoutStartCorner` 的 `SW/SE/NW/NE` 四个离散方向，但其语义冻结为区域 WCS 包围盒的网格相位锚点：

- `SW`：候选竖线从包围盒西侧按砖宽递增，候选横线从南侧按砖高递增；
- `SE`：从东侧向西、从南侧向北；
- `NW`：从西侧向东、从北侧向南；
- `NE`：从东侧向西、从北侧向南。

锚点允许位于房间外，也不要求是边界顶点。它只决定无限 WCS 网格的相位和两个生成方向，不承诺“第一块完整砖”的角与该点重合。矩形输入时，该语义与 SC1 的四角结果逐线一致。

命令交互冻结为“砖宽 → 砖高 → 包围盒网格锚点 → 选择 4 条及以上 `LINE`”。默认砖宽/高均为 600 mm，默认锚点为 `SW`。输出图层固定为 `TILE_LAYOUT_ORTHO`。

## 3. 核心公共接口

核心继续不引用 Autodesk 程序集，新增以下宿主无关契约：

- `AxisAlignedOrthogonalPolygon`：规范化后的逆时针简单环顶点、WCS 包围盒和统一高程；首尾顶点不重复保存；
- `OrthogonalRoomValidator.Validate(IReadOnlyCollection<LineSegment3D>)`：建立确定性的端点图，验证并返回一个规范化房间；
- `OrthogonalRoomValidationResult` / `OrthogonalRoomValidationError`：稳定错误分类和可读消息；
- `OrthogonalTileGridCalculator.Calculate(AxisAlignedOrthogonalPolygon, TileLayoutParameters)`：生成并裁切参数化 WCS 网格；
- `OrthogonalTileLayoutResult`：保留房间、参数、包围盒完整模数、包围盒余量和最终室内片段。

现有 `RectangleValidator`、`TileGridCalculator` 和 `TileLayoutResult` 不改语义。

## 4. 确定性端点归并与闭环验证

验证顺序冻结为：数量、有限坐标、统一高程、非退化、WCS 轴对齐、坐标归并、重叠/相交、顶点度数、单一连通环、规范化。

### 4.1 公差归并

- 继续使用 `GeometryTolerance.Coordinate = 1e-6 mm`；
- X、Y 坐标分别排序并建立“相邻差小于等于公差”的候选连通组；
- 若一个候选组的最大值与最小值之差超过公差，视为链式吸附歧义并拒绝，不按输入顺序贪心选择；
- 合法组统一替换为 `min + (max - min) / 2`；统一高程也使用全部端点 Z 的最小/最大中点；
- 以上规则只依赖排序后的数值集合，因此与选择顺序和 `LINE` 方向无关。

归并后若线退化则拒绝。相同或反向重复线、同一轴线上的部分重叠线均拒绝；只在共同端点首尾相接的共线碎段允许进入端点图。

### 4.2 图与规范化

- 每个归并后顶点的度数必须恰好为 2；小于 2 表示断口/悬挂，大于 2 表示分叉；
- 全部边必须从一个确定起点遍历一次且只形成一个连通闭环；两个或更多分离闭环拒绝；
- 非相邻边相交、接触或端点落在另一边内部均拒绝；
- 遍历后删除度数为 2 的共线中间顶点，相当于确定性合并相邻共线碎段；
- 规范化环统一为逆时针，并从 `(X 最小，再 Y 最小)` 的顶点开始；因此同一几何在任意选择顺序和线方向下得到逐点相同的结果；
- 规范化后至少四边、面积严格大于公差。

## 5. 网格线裁切规则

先按房间包围盒和锚点生成严格位于包围盒内部的候选竖线与横线，再分别裁切为零个、一个或多个室内区间。

- 竖线只与水平边求交，横线只与竖直边求交；
- 顶点命中采用半开规则 `[较小坐标, 较大坐标)`，同一顶点只计一次；
- 交点排序后按奇偶规则两两组成室内区间；凹角和 U 形等情况可产生多个互不连续片段；
- 与凹口边界共线的候选线只保留实际室内一侧，不重复生成房间边界；
- 区间若重叠或间距小于等于公差则合并，但不得跨越大于公差的室外缺口；
- 最终长度小于等于 `GeometryTolerance.Coordinate` 的数值碎片丢弃且不计数；大于公差的窄小合法片段保留；
- 输出顺序确定：先按锚点方向排列候选竖线，再排列候选横线；同一候选线上的片段始终按 WCS 小坐标到大坐标排序，片段端点也按小坐标到大坐标保存。

## 6. 片段上限与资源安全

`TILEORTHO` 单次最终室内片段上限冻结为 10,000，与既有参数化命令数值一致，但按最终片段而不是候选网格线计数。

1. 先用包围盒数值路径计算候选竖/横线数量；候选数已超过 10,000 时直接拒绝；
2. 候选数安全后逐线裁切并只累计片段数；累计达到 10,001 时立即抛出 `TileLayoutLimitExceededException`；
3. 只有完整计数不超过上限后才创建最终只读结果集合；
4. 恰好 10,000 个最终片段允许，10,001 个拒绝；图层创建发生在核心计算成功之后。

## 7. AutoCAD 事务边界

`TILEORTHO` 沿用已验证的模型空间、毫米单位、只读输入快照、单事务图层创建/复用、实体写入、异常不提交、原线保护和不自动保存规则。

- 选择器只过滤 `LINE`，允许 4 条及以上；
- 所有边界验证和 10,000 片段检查均在创建/修改 `TILE_LAYOUT_ORTHO` 前完成；
- 原边界始终只读打开；
- 图层和全部片段在同一个命令事务中提交，紧接命令的一次 `U`/`UNDO` 可整体撤销；
- 已有同名图层只复用，不改颜色、线型、线宽或锁定状态；
- 插件不调用保存命令。

## 12. OR2：四边及以上复杂正交房间能力复核

OR2 没有重写 `OrthogonalRoomValidator` 或 `OrthogonalTileGridCalculator`。代码复核和新增回归确认：两者从 OR1 起就以“单一、简单、无洞的 WCS 轴对齐闭环”为通用契约，而不是只按矩形、L 形或 U 形分支处理。`TILEORTHO` 的模型空间 `LINE` 选择、只读快照、验证、核心计算、成功后建层和单事务写回路径也无需变更。

### 12.1 已支持的房间类型

| 类型 | 结论 | 依据 |
|---|---|---|
| 四线矩形、共线分段矩形 | 支持 | 共线中间顶点会规范化合并；矩形仍与既有网格逐线兼容。 |
| L 形、U 形 | 支持 | 已有顶点命中和单网格线多室内片段回归。 |
| 一个或多个局部外凸、内凹、凹凸组合、阶梯边界 | 支持 | 只要仍是单一简单闭环；OR2 新增 14 顶点多凹凸阶梯房回归。 |
| 狭长通道 | 支持 | 只要裁切后片段长度大于 `GeometryTolerance.Coordinate`；OR2 保留 200 mm 通道片段。 |
| 同一候选网格线的多个室内片段 | 支持 | 奇偶配对后逐段输出，不能越过室外缺口合并；U 形和 OR2 阶梯房均覆盖。 |
| 大 WCS 坐标 | 支持 | 面积以相对首顶点计算；OR2 对 `1e12` 偏移的复杂阶梯房保持同样 16 段结果。 |

网格相位仍只由包围盒 `SW/SE/NW/NE` 锚点决定。它不是门洞控制、局部改相位、局部起铺或美观择优；这些语义不因 OR2 而改变。

### 12.2 明确拒绝与留待后续的矩阵

| 输入或需求 | 当前结论 | 稳定行为 |
|---|---|---|
| 内部孔洞、柱洞 | 明确拒绝 | 内外两个闭环会返回 `MultipleDisconnectedLoops`；不把内环猜成孔洞。 |
| 多个互不相连房间 | 明确拒绝 | 返回 `MultipleDisconnectedLoops`。 |
| 自交、非相邻接触、端点落在线内部 | 明确拒绝 | 返回 `IntersectingOrTouchingBoundary`。 |
| T 形连接、悬挂边、断口 | 明确拒绝 | 分别在相交检查或端点度数检查中返回 `IntersectingOrTouchingBoundary` 或 `InvalidVertexDegree`。 |
| 重复线、反向重复、部分共线重叠 | 明确拒绝 | 返回 `DuplicateOrOverlappingLine`。 |
| 斜线、圆弧、旋转房间 | 明确拒绝 | 选择器只接受 `LINE`；斜 `LINE` 返回 `NonAxisAlignedLine`，圆弧不进入选择集。 |
| 不同高程 | 明确拒绝 | 返回 `NonCoplanar`。 |
| 门洞控制与复杂房间组合 | 留待后续 | DOR 规则中的主次区、第二绝对下限和择优规则未冻结。 |
| 墙砖对缝、审美择优、局部改相位 | 留待后续 | 不猜测权重或连接关系，继续使用单一包围盒相位。 |
