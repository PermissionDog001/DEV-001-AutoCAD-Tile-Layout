## 目的和边界

M4 使用一张来源真实、已经脱敏的 DWG 副本，验证 M3 在接近实际图纸的环境中仍符合 V0.1 契约，重点检查：

1. 输入墙线位于实际业务图层、非当前图层或锁定墙线图层时，插件仍只读处理墙线；
2. 实际非原点坐标和非零统一高程不会改变西南角起铺规则；
3. 附近存在多段线、圆弧、文字、标注、填充等对象时，选择过滤和错误提示可理解；
4. 重复执行只追加本次结果，不修改原墙线，一次撤销只撤销最近一次命令；
5. 错误场景不留下部分分格线，也不自动保存图纸；
6. 只在发现可重复的产品缺陷时做聚焦修复并增加回归测试。

V0.1 不新增旋转房间、自定义 UCS、异形边界、多房间联动、去重或排版优化能力。重复执行同一房间会再次生成一组分格线，这是当前固定边界，不把它误记为幂等行为。

## 数据保护与副本链

### 1. 原始输入

- 原始 DWG 只放在本机 `inputs`，保持原文件名和内容不变；
- 开始前记录原始 DWG 的文件大小、只读属性、最后写入时间和 SHA-256；

- `inputs` 默认被 Git 忽略，原始 DWG 不提交。

### 2. 脱敏工作副本

先把原始 DWG 复制到被 Git 忽略的 `work/m4-redaction`，只打开该工作副本。推荐在工作副本中用 `WBLOCK` 导出一间代表性房间及少量邻近对象，基点使用 WCS `0,0,0`，从而保留真实坐标和高程。不要把未脱敏中间文件放进 `tests/fixtures`。

脱敏至少检查并移除或替换：

- 项目名、建设单位、设计单位、人员姓名、电话、地址和图签；
- 文字、标注内容、块属性、超链接、字段、表格和二维码；
- 外部参照、图片、PDF/DGN 底图、数据链接和云路径；
- 布局、视口、命名视图、图纸集信息、地理位置和不必要的自定义属性；
- 含业务含义的图层名、块名和文件名；
- 与测试无关的房间、轴网和隐藏对象。

最终副本应只保留：四条代表房间完成面内边界的独立 `LINE`、少量用于验证选择过滤的无敏感邻近对象，以及完成本验收所必需的匿名图层。用 AutoCAD“图形特性”和布局标签再次人工检查后，另存为：

最终文件进入 `tests/fixtures` 前必须由用户确认已经脱敏。DWG 是否加入 Git 需另行明确授权；M4 本身不授权提交。

Codex 不自动启动或强制关闭 AutoCAD。需要实机时由用户按以下步骤操作：

1. 正常保存并关闭其他重要图纸；不要关闭 AutoCAD 进程来配合构建；
2. 只打开 `tests/fixtures/m4-real-room-sanitized.dwg`；
3. 确认标题栏文件名是脱敏副本；
4. 输入 `ABOUT`，记录 AutoCAD 完整产品名和版本；
5. 输入 `INSUNITS`，确认值为毫米；输入 `TILEMODE`，确认值为 `1`；
6. 输入 `UCS` 后选择 `World`，并确认当前在模型空间；
7. 执行 `NETLOAD`，加载 `build\plugin\Debug\TileLayout.AutoCAD.dll`；
8. 确认命令行显示正式插件 `0.1.0` 已加载，再开始下表测试；
9. 每个错误场景使用独立副本或先恢复到已知状态，避免上一个测试污染统计；
10. 测试结束时先记录结果，再关闭副本并选择“不保存”；仅在明确需要保留验收证据时由用户手动保存脱敏副本。

## 数值核对

对代表房间记录 `west`、`east`、`south`、`north` 和统一 `Z`，人工计算：

```text
W = east - west
H = north - south
完整列数 = floor(W / 600)，600 整数倍公差内按整除处理
完整行数 = floor(H / 600)，600 整数倍公差内按整除处理
东侧余量 = W - 完整列数 × 600
北侧余量 = H - 完整行数 × 600
预期竖向线数 = max(完整列数 - (东侧余量为 0 ? 1 : 0), 0)
预期横向线数 = max(完整行数 - (北侧余量为 0 ? 1 : 0), 0)
预期内部分格线数 = 预期竖向线数 + 预期横向线数
```

因此，当存在东侧余量时，竖向内部线数等于完整列数；存在北侧余量时，横向内部线数等于完整行数。最终以 `TileGridCalculator` 的冻结公差规则和实际端点核对为准。

## 缺陷处理门

只有同时满足以下条件才修改产品代码：

1. 在脱敏副本或更小的无敏感夹具上可以稳定重复；

5. 能为核心、宿主无关适配函数或最小宿主步骤增加回归验证。

修复应只改完成该缺陷所需文件。修复后重新运行 M2/M3 的 Debug/Release 构建和全部自动测试，并只复测受影响的 M4 项及相邻高风险项。
