# DR5-S 顶层静态门块辅助识别冻结与证据

## 1. 当前结论

DR5-S 从 DR5 的未提交本地工作树继续，但不把动态块结论外推到静态块。2026-07-28 使用 AutoCAD 2021 Core Console `R.47.0.0` 和一次性只读检查探针，重新读取 `work/dr5-inspection` 中 S1/S2/S3 工作副本；探针只以 `OpenMode.ForRead` 枚举模型空间顶层对象并在内存中 `Explode`，没有保存 DWG。检查后七份工作副本的大小和 SHA-256 均与各自只读 `inputs/dr5-intake` 原件一致。

本轮确认：现有单扇门都是 `Autodesk.AutoCAD.DatabaseServices.BlockReference` / `AcDbBlockReference`，`IsDynamicBlock=false`，没有动态属性。它们不是现有 `DoorGeometryRecognizer` 支持的“单门扇线 + 圆弧”，而是“4 条 LINE 组成有厚度的矩形门扇 + 1 条 ARC”。因此不能直接删除 `StaticBlock` 门禁，也不能把静态块送入原单线签名后宣称支持。

2026-07-28 的 R2 已使 S1/S2/S3 各两个唯一 H/J 全部通过现有四线矩形和原 `DoorOpeningPointAdapter`；R3 的 `dr5s-s1b-sanitized-a.dwg` 又以真实顶层静态块取得两个不同完整签名并正确返回 `Ambiguous (MultipleDistinctSignatures)`。2026-07-29 的 R5 最终补齐同一正门几何的“非镜像 + 属性 A”和“非镜像 + 属性引用 0”两个宿主正变体，两件均为完整 4 LINE + 1 ARC、唯一 H/J，并分别由原适配器直通南墙和东墙。G3 全部门槛已经达到，产品现已接入受冻结静态签名约束的显式对象路径；顶层块、XREF、均匀缩放、唯一静态签名和原点适配门禁均继续保留，动态路线的识别算法和暂停状态没有改变。

## 3. 展开几何事实

七个可用于人工端点校核的单扇门具有同一结构：

- 两条平行长边各约 975 mm；
- 两条短边各约 50 mm，四线闭合成矩形门扇；
- 开启弧半径约 975 mm；
- 弧心位于铰链侧 50 mm 短边的中点；
- 弧的关闭位置端点与铰链短边方向共线；
- 弧的开启位置端点落在自由端角点的半个门扇厚度范围内；真实文件存在约 0.321 mm 的制图端点偏差，不能要求它与自由端角点按 `1e-6 mm` 完全重合。

设长边/弧半径为 `L`，短边厚度为 `T`，弧心为 `C`，弧的关闭位置端点为 `J`，则洞口铰点侧端点必须由几何确定为：

```text
H = C - unit(J - C) × T / 2
opening width = L + T / 2
```

这不是“典型 1000 mm 门宽”规则。当前样本只是恰好得到 `975 + 25 = 1000 mm`；算法不得写死 50、975 或 1000。

## 4. 静态双线门扇签名

静态几何识别只允许以下确定性签名：

1. 四条有限、非退化 `LINE` 组成一个闭合矩形门扇：两条等长平行长边、两条等长短边；不得靠对象顺序指定四条线。
2. 存在有限、非退化 `ARC`，弧心在集中坐标公差内等于其中一条短边的中点。
3. 弧半径在集中坐标公差内等于两条长边长度，且大于半个短边厚度。
4. 弧的两个端点中恰有一个与铰链短边方向共线，作为关闭位置门框端点 `J`；另一个必须位于自由端两个角点中恰好一个的 `T/2` 范围内。
5. `H` 只能按第 3 节公式生成，并且必须与铰链短边的一个实际端点在集中坐标公差内重合。
6. 线方向、弧端点方向、选择顺序、四向旋转和镜像不得改变规范化后的无序 `H/J` 端点对。
7. 重复图元表达同一端点对时只算一个候选；出现两个或更多不同端点对时为 `Ambiguous`，不得择最近、最长或第一个。
8. 静态几何候选产生后仍必须原样进入 `DoorOpeningPointAdapter.ProjectToRoomWall`；不同高程、异墙、超墙段、墙角歧义和离墙均沿用现有拒绝。

允许忽略不参与签名的辅助实体，但它们若与其他线弧组合出第二个完整端点对，必须歧义回退。属性引用、块名、有效名、图层、颜色、文字、属性标签/值和门宽数值不进入签名，也不用于打破歧义。

## 7. 现有流程复用评估

- `DoorGeometryRecognizer`：不能直接复用算法；它只接受弧心落在单条门扇线端点且线长等于弧半径的签名，与真实静态双线门扇不相容。该动态路线代码和测试保持原样。
- `DoorGeometryRecognitionResult`、状态、拒绝码及候选规范化语义：可以复用，使静态核心保持相同的 `High/Ambiguous/Unsupported` 契约。
- `DoorOpeningPointAdapter`：必须复用且不得放宽。旧 S1c 样本应通过，旧 S2 样本应以 `PointAdapterRejected` 回退；新 intake 的 S2 已消除 100 mm 偏移，但仍须先有通过现有验证的合法四线矩形。不新增“最近墙”或墙厚补偿。
- 现有只读展开器：递归 `Explode`、WCS `LINE/ARC` 收集、XREF/代理/嵌套/平面/缩放检查可在 G3 后抽成静态/动态共用读取层；当前不改产品读取入口。
- 原摘要、DR2 候选、临时预览、翻转、重选、接受、单事务写回和一次撤销：静态候选只有在未来通过原点适配后才能原样复用，不建立第二套预览或事务流程。
