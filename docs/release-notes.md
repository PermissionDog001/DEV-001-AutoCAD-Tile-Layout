# 本次更新说明

## 这次更新带来了什么

这次更新主要让自动排砖更贴近实际施工图的画法，同时保留原有命令和原图保护方式。

- **灰缝设置**：默认灰缝为 `1.5 mm`，也可以设置为 `0`。砖与砖之间按完整灰缝排布，砖与墙之间按灰缝的一半留边。例如灰缝为 `1.5 mm` 时，墙边灰缝为 `0.75 mm`。图面显示灰缝两侧的边界线。
- **闭合多段线房间**：除了原来的 `LINE`，现在可以直接选择一个闭合的直线型 `LWPOLYLINE`、传统二维 `POLYLINE` 或 `3D POLYLINE` 作为房间边界。凹进的直角房间也可以使用。原多段线只读取，不修改、不炸开、不移动。
- **复杂房间起铺点**：当最远墙一端受转角或台阶影响无法形成合格的四砖灰缝交界时，程序会检查同一面墙的另一端；起铺点仍按贴墙整砖/半砖确定，箭头与实际铺贴方向一致。
- **多段线读取稳定性**：支持直线型 `3D POLYLINE`，并允许不超过 `3 mm` 的首尾绘图误差；超过上限时显示实际首尾间距，便于修正。圆弧、bulge、非共面、自交和多环边界仍不支持。
- **抹灰完成面**：默认厚度为 `0 mm`。设置正数后，程序先把原始边界向房间内部偏移，得到完成面，再按完成面计算排砖。厚度不是 `0 mm` 时，完成面边界也会随正式图面一起写入。
- **操作更直观**：选择方案后会自动显示预览；修改砖、灰缝或完成面设置后，旧预览和旧确认会自动失效，避免把旧方案误写入图纸。连续刷新和切换方案时界面响应也更快。
- **原有功能保持不变**：`TILE600`、`TILELAYOUT`、`TILEORTHO`、`TILEDOORRECT` 的既有流程继续保留；灰缝设置只用于新的引导式排砖入口，旧命令继续按 `0 mm` 灰缝运行。

## 安全行为

- 预览、取消、修改设置、失败和没有最后确认时，不会向图纸写入对象。
- 只有用户最后点击确认写入后，程序才会在专用图层创建正式线。
- 原始 `LINE`、`LWPOLYLINE`、二维 `POLYLINE` 和 `3D POLYLINE` 不会被修改。
- 正式写入可以用一次 AutoCAD `UNDO` 撤销；插件不会自动保存或覆盖 DWG。

## 使用前请注意

- 只支持 AutoCAD 2021、模型空间和 WCS 世界坐标中的水平/竖直边界。
- 一间房只能使用一种边界来源：要么选择多条 `LINE`，要么选择一个闭合多段线，不能混用，也不能选择多个环或带洞边界。
- 多段线不能包含圆弧、bulge、自交、重复边或重叠边；仅支持直线型 `3D POLYLINE`，非直线型 3D 多段线仍不支持。
- 抹灰厚度只能是有限的非负数；负数、偏移后房间消失或边界相交时，程序会清除旧预览、不生成方案，也不写回图纸。
- 门洞两点应位于同一段外墙边缘。设置抹灰后，按界面提示在完成面边界捕捉；必要时也可以捕捉原始外墙，程序会换算到完成面。
