# 自动起铺点标志规则

状态：已完成并通过 AutoCAD 2021 实机验证

确认日期：2026-08-12

## 1. 适用范围

本规则只作用于引导式 `TILEUI` / `TILEORTHOUI` 流程。`TILE600`、`TILELAYOUT`、`TILEORTHO` 和 `TILEDOORRECT` 的既有行为保持不变。

起铺点是告诉施工人员“从哪里开始贴铺”的图面标志，不是重新计算排版相位，也不是把起铺点固定在屏幕坐标或房间中心。

## 2. 位置规则

1. 先按门洞所在墙确定对侧的远墙；没有门洞时使用当前方案的远墙语义。
2. 在远墙一侧的第一排或第一列中寻找贴墙位置。贴墙侧对应的边砖必须是整砖或半砖，才作为可控的起铺尺寸。
3. 标志中心放在四块相邻瓷砖的交界灰缝中心，不放在瓷砖中心，也不放在任意墙边中点。存在非零灰缝时，取实际灰缝的中心线交点。
4. 如果当前方案找不到满足整砖/半砖条件的候选位置，不生成起铺点标志；这不改变该方案的排版结果。

## 3. 箭头规则

- 向内箭头从远墙指向房间内部，表示离开远墙的铺贴方向。
- 沿墙箭头指向该方案实际的铺贴大方向，即从起铺侧向相邻砖列/行推进的方向。
- 两个箭头由房间、门洞、砖方向和候选相位共同决定，不能按屏幕朝向或固定 WCS 象限硬编码。

## 4. 预览和正式写回

- 预览阶段使用临时实体显示标志，不打开正式图层、不写入数据库。
- 用户最终确认后，标志与同一份 `LayoutDrawingPlan` 的分格线、尺寸标注和完成面一起写回；写回仍是一个事务和一个 AutoCAD `UNDO` 边界。
- 正式图层为 `TILE_LAYOUT_ORTHO_START`，默认 ACI 颜色为 `3`。标志由圆、十字、两个三线开放箭头和“起铺点”文字组成，共 10 个实体。
- 取消、切换方案、修改设置、预览失效或写回失败时，不留下起铺点正式对象；原始房间边界不修改，插件不自动保存 DWG。
