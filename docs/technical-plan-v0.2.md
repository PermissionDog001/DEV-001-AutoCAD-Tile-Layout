# V0.2 技术方案与开发顺序

> 状态：方案已冻结；M6 至 M9 已完成，M10 待开始
> 日期：2026-07-20
> 需求基线：`docs/requirements-v0.2.md`
> 文档定位：保留 V0.2 参数化矩形产品线 M6～M10 的历史技术计划；当前跨产品线的 DOR7/DOR8 路线、验收门和实机测试预算见 [development-roadmap.md](development-roadmap.md)。

## 1. 技术判断

V0.1 已把矩形验证、网格计算与 AutoCAD 写回分离，但砖宽和砖高仍由 `TileLayoutRules` 固定为 600 mm。V0.2 应参数化网格规则，不复制第二套计算算法，也不把 AutoCAD 输入对象传入核心层。

本版本继续使用 `AxisAlignedRectangle`。旋转矩形需要新的局部坐标模型和坐标变换，不在本次参数化中顺带实现。

## 2. 建议核心契约

- 新增不可变的砖规格/排版参数模型，至少包含 `TileWidth` 和 `TileHeight`。
- 参数模型负责有限数值、正值和公差边界验证。
- `TileGridCalculator` 接收房间和参数，返回包含所用砖规格的排版结果。
- 内部线数先以不会溢出的数值路径计算并检查 10,000 条上限，再创建结果集合。
- 余量、公差和线坐标继续集中在核心层，AutoCAD 项目不得复制公式。
- 现有固定 600 mm 入口可作为兼容包装调用参数化核心，确保 `TILE600` 只有一套算法来源。
- `TileLayoutResult` 应能支持成功消息读取实际砖宽和砖高，同时保持既有统计语义。

最终类型名可在编码时按现有命名风格确定，但不得改变上述职责边界。

## 3. AutoCAD 适配方案

- `TILE600` 保持命令名、提示、默认规则和 `TILE_LAYOUT_600` 图层不变。
- 新增 `TILELAYOUT`，先读取砖宽和砖高，再选择四条 `LINE`。
- 两个参数均显示 600 mm 默认值；非法值使用宿主提示重新输入，取消则在选择前退出。
- 新命令复用现有模型空间、毫米单位、选择过滤、只读快照、矩形验证、图层复用、事务写回和异常回滚路径。
- 把命令中可共享的流程提取为小而明确的内部方法，避免复制完整 `TILE600` 实现；不得为本次功能建设窗口、服务容器或复杂框架。
- `TILELAYOUT` 固定写入 `TILE_LAYOUT`，现有同名图层属性保持不变。
- 命令消息格式继续放在可脱离 Autodesk 程序集测试的适配文本代码中。

## 4. 自动测试策略

核心测试优先覆盖：

1. 冻结需求中的五个最小数值样例；
2. 方砖、矩形砖和交换宽高后的确定性结果；
3. 偏移原点和非零统一高程；
4. 小数规格及整数模数公差边界；
5. 宽、高为零、负数、NaN、正负无穷及小于等于公差；
6. 砖规格大于房间尺寸；
7. 10,000 条允许、10,001 条拒绝，并验证拒绝发生在结果集合分配前；
8. 极小正数不会溢出、卡死或分配海量对象；
9. 现有 `TILE600` 几何、统计和消息回归。

宿主无关适配测试覆盖：新成功消息、参数错误消息、超限消息以及 V0.1 消息回归。AutoCAD API 的提示取消、图层和事务行为由实机矩阵补充，不伪造宿主通过结果。

## 6. M9 最小实机矩阵

- `TILE600` 在已知脱敏房间中仍生成 V0.1 的 23 条结果并可一次撤销。
- `TILELAYOUT` 使用 600 × 600，与同一房间的 V0.1 几何一致，但写入 `TILE_LAYOUT`。
- 使用至少一种矩形砖和一种非 600 方砖，人工核对列行、余量、线数和关键坐标。
- 交换矩形砖宽高，确认方向按 WCS X/Y 明确变化且不自动旋转。
- 参数取消、零值/负值、选择取消和无效四线均无输出残留。
- 超过 10,000 条的预估场景在图层创建前拒绝；恰好 10,000 条的自动核心边界必须通过，是否在实机实际生成 10,000 条由 M9 风险评估决定，不强制用宿主做压力测试。
- 既有 `TILE_LAYOUT` 属性不被修改；重复执行按需求追加。
- 成功后一次撤销本次全部新增；失败事务不留部分结果；关闭不保存后重开无测试改动。

## 7. 发布与兼容性

- 目标版本：`0.2.0`，程序集版本和文件版本在 M10 统一更新。
- 正式包继续只包含运行所需 DLL 和使用说明，不包含 Autodesk DLL、测试组件、PDB、DWG、缓存或日志。
- V0.1.0 Release、标签和本地包保持历史只读，不覆盖或重打标签。
- 未经用户明确授权，不提交、推送、创建 PR 或发布 V0.2.0。

## 8. 当前状态

截至 2026-07-21，M6 参数化核心、M7 AutoCAD 适配、M8 自动质量门和 M9 AutoCAD 2021 脱敏 DWG 实机验收均已完成。M9 确认 `TILE600` 兼容、`TILELAYOUT` 默认/非法/取消、方砖和矩形砖方向、关键坐标、`TILE_LAYOUT` 属性保持与重复追加、11,199 条图层前拒绝、一次撤销、原墙线保护和不自动保存均符合冻结需求；未发现可复现产品缺陷。恰好 10,000 条仅保留自动核心边界，未人为注入实体写入/提交异常，原因和证据边界见 `docs/dwg-acceptance-m9.md`。程序集版本、`dist`、V0.1.0 历史发布和原始 DWG 保持不变；M10 待开始。
