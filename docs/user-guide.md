# 用户使用说明

## 1. 准备工作

使用前请确认：

- 已安装 Autodesk AutoCAD 2021；
- 当前在模型空间，单位按毫米使用；
- 房间边界位于 WCS 的水平或竖直方向；
- 测试时使用 DWG 副本，不直接使用原始图纸。

如果使用源码编译插件，请先按 README 的“构建、测试与加载”说明生成 `TileLayout.AutoCAD.dll`，然后在 AutoCAD 中执行 `NETLOAD` 加载该 DLL。

## 2. 选择命令

推荐普通用户使用 `TILEUI`。旧名称 `TILEORTHOUI` 仍然可以使用，两者打开同一个引导式窗口。

| 命令 | 用途 |
| --- | --- |
| `TILEUI` | 推荐入口，按窗口提示完成房间、门洞、设置、方案预览和写入。 |
| `TILEORTHOUI` | 与 `TILEUI` 相同的兼容入口。 |
| `TILE600` | 原有 600 × 600 mm 矩形房间流程，固定使用 0 mm 灰缝。 |
| `TILELAYOUT` | 原有矩形房间流程，可输入砖宽、砖高和起铺角，固定使用 0 mm 灰缝。 |
| `TILEORTHO` | 原有正交房间流程，固定使用 0 mm 灰缝。 |
| `TILEDOORRECT` | 原有门洞矩形流程，固定使用 0 mm 灰缝。 |

## 3. 推荐操作顺序

### 第一步：选择房间和设置

在窗口中点击“选择房间”，然后按提示在图中选择边界：

- 可以选择组成房间的一组 `LINE`；
- 也可以只选择一个闭合 `LWPOLYLINE` 或传统二维 `POLYLINE`；
- 一间房不能把 `LINE` 和多段线混在一起，也不能选择多个边界环。

在设置中输入：

- 砖宽、砖高；
- 砖间灰缝，默认 `1.5 mm`，允许 `0`；
- 抹灰完成面厚度，默认 `0 mm`，只允许 `0` 或正数。

保存设置后，旧预览和旧的人工确认会自动失效，需要重新查看方案。

#### 项目铺贴规则

项目规则中的“建议下限比例”默认是 `0.5`，可修改为 `0 < 比例 ≤ 0.75`。这里的 `T` 是对应方向的砖尺寸：X 方向使用砖宽，Y 方向使用砖高。例如 600 mm 砖输入 `0.5`，建议下限就是 300 mm。它用于判断边砖是否低于建议值；低于建议值的方案会进入项目规则判断或图面复核，不等于所有方案都会直接淘汰。

保存项目规则时，建议下限比例和“项目最低允许尺寸”处理方式一起确认：

- **设置项目最低允许尺寸或比例**：在“最低允许尺寸（mm）”和“最低允许比例（T）”中二选一。按比例设置时，X/Y 方向分别用砖宽/砖高换算为毫米。低于换算结果的方案会被淘汰；介于最低允许值和建议下限之间的方案仍可能需要看图复核。
- **按图面确认**：不设置固定最低尺寸。程序会显示实际边砖尺寸，用户查看预览后再作最终确认。
- **暂不决定**：可以继续查看方案，但项目规则未完成，不能正式写回图纸。

默认选中“按图面确认”，因为它不预先替用户设定硬性淘汰尺寸；如项目已有明确的毫米下限或比例下限，再切换到第一项并保存。

“优先考虑房间转角处的砖缝”是可选的排序偏好，只在满足硬性规则的方案中比较转角砖缝和入口观感，不会放宽最低尺寸，也不会直接修改图纸。

### 第二步：设置门洞（如需要）

按窗口提示选择门洞两侧边缘点。两个点必须在同一段外墙边缘上，不能一个点在墙角、另一点在另一面墙上，也不能选择房间内部的共享边。

如果设置了抹灰厚度，程序会以抹灰后的完成面计算门洞、控制区域和排版；按提示捕捉完成面边界即可。捕捉到原始外墙时，程序会同步换算到完成面。

### 第三步：选择方案

程序会把方案分为“满足规则”“需要人工确认”和“不可使用”。选择一个方案后会自动显示临时预览；预览只显示在屏幕上，不会写入 DWG。

如果方案提示需要确认，请先阅读最窄边砖位置和尺寸，再决定是否继续。修改房间、门洞、砖、灰缝或抹灰设置后，必须重新查看方案。

第 1 页默认勾选“自动添加尺寸标注（建筑样式，默认勾选）”。大面只选择房间内连续通长的代表性第一行和连续通宽的代表性第一列，链内每块砖逐块生成通用尺寸链；房间内模式优先选择最接近房间中心且不贴边界的砖边，避免斜短线遮挡阳角、墙角和对缝关系。特殊切砖、异形砖和特殊位置每块砖每个方向只补充最长必要尺寸，并与通用标注按轴向数值去重。房间凹边、凸边、转角等台阶本身默认不标注，只有勾选可选入口后才标注其长度/深度。标注位置默认房间内，也可切换为房间外外置尺寸链；尺寸界线端点与实际砖边/房间边界重合。标注值按实际砖边长度以毫米四舍五入为整数显示，不带 `mm` 后缀。

同一页还可以选择瓷砖分割线、砖尺寸标注、凹凸/特殊标注和抹灰边界的 AutoCAD ACI 颜色。默认颜色为 ACI 3 绿色、ACI 2 黄色、ACI 6 品红和 ACI 4 青色。

如果图面过密，可以取消勾选后重新预览；这只关闭当前方案的自动标注，不改变排版候选和砖缝计算。取消后正式写回不会创建或写入 `TILE_LAYOUT_ORTHO_DIM` 标注图层。

#### 自动起铺点标志

引导式流程会在方案预览中显示自动起铺点标志。它不是房间中心点，也不是任意一个砖缝点，而是位于远离门口墙面的第一排或第一列、贴墙整砖或半砖对应位置的四块砖交界灰缝中心。这样工人可以从整砖或半砖控制起铺尺寸。

标志的两个箭头含义固定为：一个箭头由远墙指向房间内部，另一个箭头指向该方案实际的铺贴大方向。箭头方向随门洞位置、排版相位和砖的横/竖方向变化，不按屏幕方向硬编码。若当前方案找不到满足整砖或半砖条件的墙边位置，程序不生成起铺点标志，并保留方案本身的排版结果。

预览中的标志只显示在屏幕上；只有点击最后的“确认并写入图纸”后，标志才会和分格线、尺寸标注一起正式写入 `TILE_LAYOUT_ORTHO_START` 图层。取消、切换方案、修改设置或失败时不会写入该图层。

### 第四步：核对并写入

在图面核对页确认：

- 砖缝位置是否符合预期；
- 灰缝两侧边界线是否正确；
- 抹灰完成面是否正确；
- 门洞附近和房间角部是否符合要求。
- 通长第一行、通宽第一列是否连续逐块标注，特殊切砖/异形砖是否每个方向只保留最长必要尺寸且没有与通用标注冲突，颜色是否区分；尺寸界线是否落在砖边上而没有被误认成砖缝。
- 自动起铺点是否位于远墙首排/首列的四砖灰缝中心，贴墙侧相邻砖是否为整砖或半砖，向内箭头和实际铺贴大方向箭头是否正确。

只有点击最后的“确认并写入图纸”后，正式分格线和已勾选的尺寸标注才会写入专用图层。尺寸标注正式写回时使用插件专用样式 `TILE_LAYOUT_ANNOTATION`，不依赖当前图纸的活动 DIMSTYLE。写入后如需撤销，执行一次 `U` 或 `UNDO` 即可撤销本次写入。

## 4. 边界输入要求

闭合多段线必须满足：闭合、单一外环、共面、水平/竖直、无圆弧、无 bulge、无自交、无重复边和无重叠边。程序只做确定性的连续顶点合并，不改变房间形状。

如果使用 `PL` 画矩形，请在命令结束时选择“闭合(C)”。选择时点击多段线实体本身，不要选择块内对象、外部参照或布局空间中的对象。

## 5. 常见问题

**提示“边界读取失败”**

检查是否在当前模型空间中选择了 `LINE`、闭合 `LWPOLYLINE` 或闭合二维 `POLYLINE`。`Polyline3d`、圆弧多段线、块内对象和布局空间对象不支持。

**提示门洞两点无效**

重新选择同一段外墙上的两个边缘点。不要跨墙面、不要选内部共享边、不要把墙角当作门洞端点。

**抹灰后没有方案**

检查抹灰厚度是否过大，导致窄部位消失、边界相交或房间面积不足。此时程序会清除旧预览，不会写入任何对象。

**想取消操作**

可以取消当前选择、返回上一步或取消整个任务。取消状态不会写入正式图形。

## 6. 图层和原图保护

引导式流程的正式分格结果写入 `TILE_LAYOUT_ORTHO_CONFIRMED`；自动尺寸标注写入独立图层 `TILE_LAYOUT_ORTHO_DIM`，其中砖尺寸为黄色、房间凹凸特征为品红色；自动起铺点标志写入独立图层 `TILE_LAYOUT_ORTHO_START`。抹灰厚度不是 `0 mm` 时，完成面边界也作为正式图面的一部分写入分格专用图层。原始房间边界始终保持不变，插件不会自动保存 DWG。
