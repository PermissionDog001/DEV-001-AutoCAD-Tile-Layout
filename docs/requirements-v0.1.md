# V0.1 需求基线

> 状态：已冻结用于技术原型
> 日期：2026-07-19

## 用户目标

验证 AutoCAD 2021 插件自动读取最简单矩形房间并生成 600 mm 地砖分格的可行性。V0.1 只证明技术闭环，不替代成熟人工排版规则。

## 环境

- Autodesk AutoCAD 2021
- 具体行业版本：待确认
- Windows x64
- C# / .NET Framework 4.8

## 输入约束

- 用户手动选择四条 `LINE`。
- 四条线位于模型空间。
- 四线组成闭合矩形。
- 矩形与 WCS X/Y 轴平行。
- 单位为毫米。
- 四条线代表房间完成面内边界。

不满足任一条件时，插件必须停止生成并给出可理解的错误提示。

## 固定排版规则

1. 地砖规格为 600 × 600 mm。
2. 灰缝宽度为 0 mm。
3. 第一块砖西南角与房间西南角重合。
4. 向东、向北按 600 mm 模数排列。
5. 到东侧或北侧边界后直接截断。
6. 不平移、不居中、不对称调整、不优化窄砖。
7. 不设置人工参考结果或评分器。

## 输出

- 专用图层名称：`TILE_LAYOUT_600`。
- 生成房间内部横向、竖向分格线。
- 命令行报告：房间宽、高、完整列数、完整行数、东侧余量、北侧余量。
- 命令名称暂定：`TILE600`。

## 原图保护

- 原四条墙线只读，不改变对象和属性。
- 新增对象应处于一次撤销组中。
- 插件不执行自动保存。
- 不覆盖 DWG 文件。

## 失败行为

以下情况拒绝生成：

- 选择对象不是恰好四条 `LINE`；
- 端点无法在公差内组成闭合边界；
- 房间不是矩形；
- 边界不与 WCS X/Y 轴平行；
- 宽或高小于等于 0；
- 图纸单位无法确认是毫米；
- 创建图层或写入事务失败。

失败时不得留下部分分格线；事务应回滚。

## 最小验收样例

| 房间尺寸 | 预期完整列/行 | 东侧余量 | 北侧余量 |
|---|---:|---:|---:|
| 3600 × 3000 | 6 / 5 | 0 | 0 |
| 4250 × 3100 | 7 / 5 | 50 | 100 |
| 500 × 500 | 0 / 0 | 500 | 500 |
| 600 × 600 | 1 / 1 | 0 | 0 |

## V0.1 明确不做

- 旋转矩形和 UCS 转换
- 门洞、柱、地漏、墙垛和异形边界
- 灰缝、砖缝视觉宽度和材料厚度
- 多候选方案、评分、居中和最小边砖
- 多房间联动和材料损耗
- 完整参数 UI、独立 EXE、自动升级和云服务
