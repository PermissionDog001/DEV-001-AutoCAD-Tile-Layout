## 4. DOR7：普通用户产品化交互与同源图面可视预览

### 4.1 用户结果

陌生用户应能完成以下闭环：

1. 用普通语言选择房间、砖规格和项目规则。
2. 选择“整房连续铺贴”或“划分主区和次区”；只有后者才出现主次区和连接边。
3. 在图中直接点选控制范围、门洞和必要的区域关系。
4. 看懂每个方案的图形、主要切砖尺寸、可用状态和下一步。
5. 自动方案可直接进入预览；人工方案必须选择方案并填写项目原因，且明确标为“非自动合规”。
6. 在图面查看可取消、可刷新、零写入的真实排版预览，再决定返回修改或完成本轮只读任务。

默认界面不再直接展示 `RoomControlRegion`、`DecisionRequirement`、候选 ID、内部状态码等工程术语。它们只保留在默认折叠的“工程详情”中。

### 4.2 同源绘图契约

DOR7 应在 `TileLayout.Core` 建立宿主无关、确定性的“绘图计划”模型。它只包含绘制预览和未来写回所需的线段、砖块轮廓、区域/候选标识和显示语义，不引用 Autodesk DLL。

同一个已选择候选必须只生成一份绘图计划：

```text
DOR3 真实候选
    → 宿主无关绘图计划
        → 自动生成的 SVG/快照（自动测试）
        → AutoCAD 临时矢量预览（DOR7，零写入）
        → AutoCAD 正式实体写回（DOR8，需明确确认）
```

预览层不得自行重算排版，DOR8 写回层也不得另建第二套几何算法。这样才能保证“测试看到的、用户预览的、最终写入的”来自同一份数据。

### 4.5 DOR7 实机测试预算

为减少时间和测试成本，采用“自动证据优先、宿主风险集中验证”：

- 编码期间不安排常规 AutoCAD 往返；界面和铺贴图先用宿主无关状态测试与确定性快照审查。
- 只有 G1～G6 全部通过后，才提供一次真实用户语言的 AutoCAD 2021 清单。
- 最终实机只覆盖 AutoCAD 特有风险：Palette 与命令上下文切换、图面临时矢量显示/清除、跨图恢复，以及对象/图层/事务零写入。
- 代表场景限定为：L-01 自动推荐、L-04 D 缺失规则/主次语义、L-04 E 多候选人工决定。DOR6 已验收且未改动的取消点不机械全量重跑，只做受影响路径和既有命令冒烟。
- 仅在出现无法由宿主无关测试、静态检查或确定性快照回答的 AutoCAD 特有问题时，才增加一次针对性实机测试，并记录增加原因。

## 自动尺寸标注（2026-08-11）

- 引导式 UI 第 1 页新增默认勾选的“自动添加尺寸标注（建筑样式，默认勾选）”复选框；仅作用于 `TILEUI`/`TILEORTHOUI`，四个旧命令保持原有行为。
- Core 在同一 `LayoutDrawingPlan` 中生成确定性的尺寸数据：大面选择房间内连续通长/通宽的代表性第一行、第一列并逐块形成尺寸链；特殊切砖/异形砖每块每个方向只取最长必要边并按显示尺寸去重；房间凹凸台阶尺寸默认关闭，可选开启。
- 房间内通用行/列在满足连续通长/通宽的候选中优先选择最接近房间中心且不贴边界的砖边；只有不存在内部通长/通宽带时才回退到边界带，降低斜短线遮挡阳角、墙角和对缝关系的风险。
- 标注位置默认房间内，也可选房间外；AutoCAD 预览使用临时 `RotatedDimension`，正式写回与分格线共用一个事务和一次 `UNDO` 边界；UI 提供分割线、砖尺寸、凹凸/特殊标注、抹灰边界的 ACI 常用颜色选择，标注层为 `TILE_LAYOUT_ORTHO_DIM`。
- 标注值按实际边长以 `MidpointRounding.AwayFromZero` 四舍五入到整数，不显示 `mm` 后缀；正式写回注入并使用插件专用 `TILE_LAYOUT_ANNOTATION` 标注样式；关闭复选框会清除旧预览并要求重新预览，不创建标注层。
