# 自动尺寸标注规则

状态：用户已确认规则；实现、自动验证和 AutoCAD 2021 实机图面复核均已完成。

## 1. 适用范围

- 仅接入引导式 UI（`TILEUI`/`TILEORTHOUI`）；`TILE600`、`TILELAYOUT`、`TILEORTHO`、`TILEDOORRECT` 保持既有行为。
- UI 第 1 页增加“自动添加尺寸标注（建筑样式，默认勾选）”复选框，默认勾选。
- 复选框关闭时，当前方案不生成、预览或写回尺寸标注；切换开关会使旧预览失效并要求重新预览。
- 默认标注位置为房间内；也可切换为房间外的外置尺寸链。
- UI 单独提供房间凹边、凸边、转角台阶尺寸开关，默认关闭；关闭时不标注房间台阶本身的长度/深度。

## 2. 标注内容

- 大面只选择房间内连续通长的代表性第一行和连续通宽的代表性第一列；该行、列沿贯通方向逐块形成通用尺寸链。
- 房间内模式在满足通长/通宽的候选中优先选择最接近房间中心、且不贴房间边界的砖边；只有不存在内部通长/通宽带时才回退到边界带，避免建筑斜短线遮挡阳角、墙角和对缝关系。
- 标注砖的实际尺寸，不把灰缝占位计入尺寸。
- 特殊切砖、异形砖和特殊位置单独标注；每块特殊砖在每个方向只选择最长必要边，同一轴向、同一四舍五入尺寸全图只保留一个代表性标注，并跳过已由大面通用链表达的尺寸，避免重复和冲突。
- 房间凹边、凸边、转角等台阶仅在用户打开可选开关后标注其长度/深度。
- 尺寸界线的测量端点锚定在对应砖边或房间边界上；房间内模式沿被测砖边显示，房间外模式使用外置尺寸链。
- Core 只生成确定性的标注几何；AutoCAD 适配层负责生成标准线性标注实体。

## 3. 样式与数值

- 使用 AutoCAD 建筑工程常见的箭头、尺寸界线和外置尺寸链样式。
- 正式写回时注入并使用插件专用建筑标注样式 `TILE_LAYOUT_ANNOTATION`，采用建筑斜短线箭头，不继承当前图纸的活动 DIMSTYLE；若该名称已存在，插件在本次事务中更新为本规则，随后所有尺寸标注使用该样式。
- 标注值以毫米为单位，四舍五入到整数，不显示 `mm` 后缀。
- 颜色通过 UI 选择 AutoCAD 常用 ACI 颜色：分割线、砖尺寸标注、凹凸/特殊标注、抹灰边界分别设置；默认值为 ACI 3 绿、ACI 2 黄、ACI 6 品红、ACI 4 青。
- 颜色只表达语义，不改变几何和候选状态；房间台阶标注关闭时，凹凸/特殊标注颜色仍用于特殊砖位。
- 标注写入独立图层 `TILE_LAYOUT_ORTHO_DIM`，与正式分格线分开管理。

## 4. 预览、写回与保护

- 预览消费当前候选同一份 `LayoutDrawingPlan`，使用 AutoCAD 临时对象，保持零写入。
- 最终确认后，尺寸标注与正式分格线在同一原子事务中写回，并保留一次 AutoCAD `UNDO` 边界。
- 原始房间边界不修改；取消、切换、刷新失败和未确认状态不写入尺寸标注。
- 同一房间范围的正式标注拒绝重复写回；不同房间允许追加。

## 5. 实机验收记录

- 2026-08-11，用户完成 AutoCAD 2021 实机验证，确认自动标注的建筑样式、通长/通宽逐块尺寸链、特殊位置尺寸、房间内中心位置、颜色区分和整体显示效果达到预期。
- 本规则任务已收口；后续自动设置起铺点属于独立任务，不改变本规则已确认的标注数量、样式、位置和写回边界。
